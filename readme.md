# PROJECT BILLFORGE
BillForge is an open-source billing workspace for Indian vendors. It brings invoice creation, GST-ready product records, customer Khata, receivables, inventory signals, reports, and a read-only business Copilot into one tenant-scoped application. The project is designed to make everyday business work faster without hiding what the product can and cannot do.

---

## Features
* User authentication and authorization
* Invoice creation and management
* Customer and product workspaces with search, pagination, and clear empty/error states
* Khata ledger for credit sales, payments, advances, statements, and auditable resets
* Server-authoritative GST, totals, stock checks, tenant isolation, and invoice idempotency
* Reports based on active invoices and current receivables
* Tenant-scoped JSON workspace backup from Settings
* Read-only OpenRouter Copilot with bounded business context and explicit data boundaries
* English, Hindi, and Hinglish localization with light/dark themes
* Responsive dashboard, fast invoice workflow, mobile drawer, keyboard command menu, and contextual help
* Production-minded error recovery, financial invariants, and migration checks
